# --interactive--

Porodična grupa fontova je skup fontova koji dele zajednički dizajn. Svi fontovi koji pripadaju jednoj porodici potiču iz istog osnovnog tipa fonta, ali takođe imaju razlike u stilu, težini i širini. Možete ih zamisliti kao rođake koji dele slične karakteristike, ali takođe imaju određene razlike. Na primer, Arial je porodična grupa fontova koja uključuje varijacije kao što su Arial Bold i Arial Italic.

<img src="https://cdn.freecodecamp.org/curriculum/lecture-transcripts/what-are-font-families-and-how-do-they-work-1.png" alt="Diagram showing 'Arial' at the top with two blue arrows pointing down to 'Arial Bold' on the left and 'Arial Italic' on the right, illustrating font family variations" />

U CSS, možete postaviti porodičnu tipografiju koristeći svojstvo `font-family`. Evo primera postavljanja fonta za paragraf na `Arial`:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<p id="arial-font">Example paragraph using Arial font.</p>
<p>Paragraph not using Arial font.</p>
```

```css
#arial-font {
  font-family: Arial;
}
```

:::

Lakini vipi kama familia ya fonti haipatikani? Unaweza kubainisha familia nyingi za fonti kwa mpangilio wa kipaumbele, kutoka juu hadi chini, kwa kuzitenganisha kwa koma. Fonti hizi mbadala zitafanya kazi kama njia mbadala. Katika mfano huu, Arial ni fonti kuu na Lato ni fonti mbadala:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<p id="specified-font">Example paragraph using specified fonts.</p>
<p>Paragraph not using specified fonts.</p>
```

```css
#specified-font {
  font-family: Arial, Lato;
}
```

:::

Kivinjari kitaonyesha fonti ya kwanza (Arial) ikiwa itapatikana kwenye kifaa. Ikiwa haitapatikana, fonti ya pili (Lato) itaonyeshwa.

Unapaswa pia kujua jinsi mchakato huu unavyofanya kazi nyuma ya pazia. Mchakato wa kuchagua hauishi ikiwa fonti ya kwanza inapatikana. Familia ya fonti huchaguliwa herufi moja kwa moja, hivyo ikiwa fonti haijumuishi herufi fulani, kivinjari hutatiza kutafuta herufi hiyo katika fonti zilizo na kipaumbele cha chini. Inavutia, sivyo?

Katika muktadha wa ukuzaji wa mtandao, pia utapata familia za fonti za jumla. Ni muhimu sana. Familia ya fonti ya jumla ni fonti ya msingi ambayo vivinjari vya mtandao vitaonyesha wakati fonti zilizo na kipaumbele cha juu hazipatikani. Ili kuhakikisha maudhui bado yanasomeka, kivinjari hubadilisha fonti ya awali na fonti inayofaa zaidi inayopatikana, kulingana na familia ya fonti ya jumla iliyobainishwa. Baadhi ya familia zinazotumika sana ni:

- serif
- sans-serif
- monospace
- cursive
- fantasy

Lakini kuna chaguzi zaidi za kuchagua. Katika msimbo hapa chini, tuna familia tatu mbadala za fonti:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<p id="specified-font">Example paragraph using specified fonts.</p>
<p>Paragraph not using specified fonts.</p>
```

```css
#specified-font {
  font-family: Arial, Lato, sans-serif;
}
```

:::

Arial ina kipaumbele cha juu zaidi. Ikiwa Arial haitapatikana, basi kivinjari kitajaribu kuonyesha Lato. Ikiwa hakuna kati ya hizo mbili itakapotumika, kivinjari kita tumia familia ya fonti ya jumla ya sans-serif, kuchagua fonti yenye sifa hizi kutoka kwa zile zilizowekwa kwenye mfumo wa mtumiaji.

Unapaswa kila mara kujumuisha familia ya fonti ya jumla mwishoni mwa orodha ya familia za fonti. Kumbuka kwamba fonti ya jumla inaweza kuonekana tofauti na fonti uliyokuwa umeipanga awali katika muundo wako, hivyo ni msaada kila mara kuangalia jinsi fonti hizi mbadala zinavyoonekana kwenye vivinjari tofauti.

Da bi korisničko iskustvo bilo što stabilnije, savetuje se korišćenje sigurnih web fontova. Ove porodice fontova su obično instalirane na mnogim uređajima, pa postoji velika verovatnoća da će biti dostupne i ispravno prikazane za većinu korisnika. Vi ćete saznati više o njima u narednim lekcijama.

Font-familije su važne u svetu web dizajna. Korišćenjem svojstva `font-family`, možete odmah promeniti izgled i osećaj vašeg teksta.
