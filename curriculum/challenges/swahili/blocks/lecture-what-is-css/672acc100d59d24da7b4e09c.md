# --interactive--

Mchanganyiko wa CSS hutumika kufafanua uhusiano kati ya wachaguzi katika CSS. Husaidia kuchagua vipengele kulingana na uhusiano wao na vipengele vingine, jambo linaloruhusu urembo sahihi na wenye ufanisi zaidi.

Razradićemo neke glavne mešavine CSS i njihove primene, počevši sa mešavinom semena.

Kombinacija potomaka koristi se za odabir elemenata koji odgovaraju drugom selektoru ako su postavljeni unutar roditeljskog elementa koji odgovara prvom selektoru. Roditelj može biti roditeljski element ili preporoditeljski element.

Ili kuelewa vizuri jinsi hii inavyofanya kazi, tuchukulie mfano.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

<figure>
  <img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg" alt="Relaxing Cat">
  <figcaption>A relaxing cat with a border</figcaption>
</figure>
```

```css
figure img {
  border: 4px solid red;
}
```

:::

Katika mfano huu hapo juu, tunatumia mchanganyiko wa mzao kuchagua vipengele vyote vya picha ndani ya vipengele vya `figure` na kuweka mpaka wa `solid red` upande wote wa nne.

Kumbuka kuwa `space` hutumika kati ya kichaguzi cha mzazi na mtoto.

Katika kesi hii, `figure` itakuwa mzazi na `img` itakuwa mtoto.

Ikiwa ungekuwa na picha nyingi ndani ya kipengele cha `figure`, kutumia mchanganyiko wa mzao ingekuwa njia nzuri ya kuweka mpaka giza imara kuzunguka kila moja ya picha hizo.

Druga vrsta mešavine je dečija mešavina.

Mchanganyiko wa mtoto (`>`) katika CSS hutumika kuchagua vipengele ambavyo ni watoto wa moja kwa moja wa kipengele mzazi kilichobainishwa.

Mchanganyiko huu unalenga tu vipengele vyenye mzazi maalum, na kufanya sheria zako za CSS kuwa sahihi zaidi na kuzuia urembo usiotarajiwa wa vipengele vilivyopangwa ndani kwa kina zaidi.

Uzmi primer od HTML sledeći:

:::interactive_editor

```html
<div class="container">
  <p>First</p>
  <div>
    <p>Second</p>
  </div>
  <div>
    <p>Third</p>
  </div>
</div>
```

:::

U strukturi HTML gore, klasa `container` je postavljena na elementu/atributu `div`.

U ovom kontejneru, postoji direktni element `p` ("Prvi"), praćen dva dodatna elementa `div`, svaki sa elementom `p` ("Drugi" i "Treći").

Kipengele cha kwanza cha `p` ni mtoto wa moja kwa moja wa kipengele cha `.container`, wakati vipengele viwili vya `p` vimepangwa ndani ya vipengele vingine vya `div`, na hivyo kuwa mzao wa kina zaidi.

Ili kutumia mitindo kwa mtoto wa moja kwa moja wa darasa la `container`, unaweza kutumia mchanganyiko wa mtoto kama ifuatavyo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

<div class="container">
  <p>First</p>
  <div>
    <p>Second</p>
  </div>
  <div>
    <p>Third</p>
  </div>
</div>
```

```css
.container > p {
  color: blue;
}
```

:::

Katika mfano huu hapo juu, tunalenga tu mtoto wa moja kwa moja wa darasa la `container`. Hii itampa mtoto wa moja kwa moja rangi ya maandishi ya `blue`.

Kwa kuwa vipengele viwili vya aya vimepangwa ndani ya vipengele vya `div`, havihesabiwi kuwa watoto wa moja kwa moja wa darasa la `container` na hivyo havitapokea rangi ya maandishi ya buluu.

Mchanganyiko mwingine wa kawaida ni mchanganyiko wa ndugu wa pili.

Mchanganyiko wa ndugu wa pili (`+`) katika CSS huchagua kipengele kinachofuata mara moja kipengele cha ndugu kilichobainishwa. Mchanganyiko huu ni muhimu unapotaka kutumia mitindo kwa kipengele kinachofuata moja kwa moja kipengele kingine, na hivyo kuruhusu urembo uliolengwa kulingana na nafasi ya kipengele kati ya ndugu zake.

Uzmi primer od HTML sledeći:

:::interactive_editor

```html
<figure>
  <img
    src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg"
    alt="A cute orange cat lying on its back."
  />
  <figcaption>A cute orange cat lying on its back.</figcaption>
</figure>
```

:::

Hapa, tuna kipengele cha `figure` chenye kipengele cha `img` kinachofuatiwa na kipengele cha `figcaption`. Kipengele cha `figcaption` ni ndugu wa moja kwa moja wa kipengele cha `img`.

Ikiwa ungependa kuweka mpaka mweusi kuzunguka kipengele cha `figcaption`, unaweza kutumia mchanganyiko wa ndugu wa pili kama ifuatavyo:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

<figure>
  <img
    src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg"
    alt="A cute orange cat lying on its back."
  />
  <figcaption>A cute orange cat lying on its back.</figcaption>
</figure>
```

```css
img + figcaption {
  border: 4px solid black;
}
```

:::

Katika mfano huu, mchanganyiko wa ndugu wa pili (`+`) huchagua kipengele cha `figcaption` kinachofuata mara moja kipengele cha `img`. Sheria ya CSS iliyotumika inaongeza `4px solid black border` kuzunguka `figcaption`.

Mchanganyiko mwingine wa kawaida ni mchanganyiko wa ndugu wa baadaye.

Kombinacija sledećih braće (`~`) u CSS bira sve braće navedenog elementa koje ga slede.

Za razliku od prethodnog brava mixa, koji cilja samo neposredno sledećeg brata/sestre, kombinacija naknadnih brava (`~`) može da cilja bilo kog brata/sestre koji sledi navedeni element, čime pruža veću fleksibilnost u dizajnu.

Uzmi primer od HTML sledeći:

:::interactive_editor

```html
<div class="container">
  <h2>Subheading</h2>
  <p>First paragraph.</p>
  <p>Second paragraph.</p>
  <p>Third paragraph.</p>
  <p>Another paragraph element</p>
</div>
```

:::

U ovoj strukturi od HTML, imamo element `h2` praćen sa četiri paragrafa elementa. Paragrafski elementi su braća/sestre elemenata `h2`.

Ako želite stilizovati sve elemente pasusa koji sledeći element od `h2`, možete koristiti kombinaciju budućih braće kao što sledi:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

<div class="container">
  <h2>Subheading</h2>
  <p>First paragraph.</p>
  <p>Second paragraph.</p>
  <p>Third paragraph.</p>
  <p>Another paragraph element</p>
</div>
```

```css
h2 ~ p {
  color: green;
}
```

:::

U ovom primeru, svi elementi paragrafa koji prate element `h2` će imati zelenu boju teksta.

Kombinacija sledećih braće (`~`) cilja na sve braće paragrafa koji se pojavljuju nakon elementa `h2`, bez obzira da li su direktni braća ili ne.

Zaključno, razumevanje i korišćenje različitih kombinacija CSS omogućava vam da koristite odgovarajuće stilove za vaše HTML elemente, povećavajući kontrolu i slobodu vašeg dizajna.

Sa ovim selektorima, možete kreirati složenije i ciljane pravila stila koja poboljšavaju izgled i performanse vaših web stranica.
