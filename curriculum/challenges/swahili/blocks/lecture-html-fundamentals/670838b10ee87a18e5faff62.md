# --interactive--

Funkcija `script` se koristi za ubacivanje izvršnog koda. Mnogi programeri koriste ovo za izvršavanje koda JavaScript. JavaScript se koristi za dodavanje interaktivnosti vašim veb stranicama. Uobičajeni primeri korišćenja JavaScript uključuju interaktivne igre, galerije slika (image sliders), i dinamične forme koje validiraju unos korisnika u realnom vremenu.

Ovo je primer korišćenja funkcije `script` u dokumentu HTML. Izbrišite `//` koji se nalazi ispred `alert("Welcome to freeCodeCamp");` i trebalo bi da vidite upozorenje. Da biste videli reviziju, moraćete da omogućite interaktivni editor.

:::interactive_editor

```html
<body>
  <script>
    // alert("Welcome to freeCodeCamp");
  </script>
</body>
```

:::

Iako tehnički možete napisati sav svoj kod JavaScript unutar tagova `script`, smatra se da je bolja praksa povezivanje sa eksternom datotekom JavaScript umesto toga. Evo primera korišćenja funkcije `script` za povezivanje sa eksternom datotekom JavaScript:

```html
<script src="path-to-javascript-file.js"></script>
```

Sifa ya `src` hutumika hapa kubainisha mahali pa faili hiyo ya JavaScript ya nje. `src` inasimama kwa "source" (chanzo). Sababu ya kutopendekeza kuweka msimbo wako wote wa JavaScript ndani ya hati ya HTML ni kwa sababu ya mgawanyo wa majukumu. Mgawanyo wa majukumu ni kanuni ya muundo ambapo unagawa programu zako katika sehemu tofauti na kila sehemu inashughulikia jukumu tofauti. Katika kesi hii, tunataka kutenganisha msimbo wetu wa JavaScript na msimbo wetu wa HTML.
