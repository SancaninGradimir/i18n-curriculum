# --interactive--

Algoritam Cascade je proces koji koristi pregledač da utvrdi koje će pravilo od CSS biti korišćeno kada postoji mnogo stilova koji ciljaju jedan element. Osigurava da se koristi najpogodniji stil, u skladu sa dobro definisanim setom pravila.

Proces počinje sa **vezom**. Pretraživač prvo filtrira sva pravila za CSS ili dobija ona koja se primenjuju na element o kojem se govori. Ovo uključuje poređenje selektora i uzimanje u obzir potencijalno primenljivih media upitnika (media queries).

Media query ni mbinu ya CSS inayotumika kutekeleza mitindo kulingana na sifa za kifaa au eneo la kuona, kama upana wake, urefu wake, au mwelekeo wake.

Zatim, algoritmi uzimaju u obzir **poreklo i značaj**. CSS može poticati iz različitih izvora: bazni stilovi pregledača (user-agent), stilovi postavljeni od strane korisnika, i stilovi kreirani od strane autora (vi).

Baada ya kuzingatia asili, algoriti hupima umuhimu wa kila sheria, ikitoa kipaumbele kwa sheria zilizo na `!important` ambazo hughairi sheria nyingine bila kujali chanzo chao.

Baada ya kuchuja kwa asili na umuhimu, algoriti huangalia **uwezo wa maalum**. Wakati sheria mbili kutoka asili na kiwango cha umuhimu sawa zinatumika, sheria yenye uwezo wa maalum zaidi ndiyo itakayotekelezwa.

Uwezo wa maalum ni kipimo cha jinsi kichaguzi kilivyo lengwa, ambapo vichaguzi maalum zaidi vina kipaumbele juu ya vichaguzi vya jumla.

Mwishowe, ikiwa kila kitu kingine ni sawa, **mpangilio wa kuonekana** huingia kazini. Wakati sheria mbili zina uwezo sawa wa maalum, ile inayojitokeza mwisho katika CSS ndiyo itatumika.

Hii ndiyo sababu mpangilio wa kuandika mitindo yako unaweza kuathiri matokeo.

Tuchukulie mfano.

Katika faili ya HTML, kuna kipengele kimoja cha aya. Kisha ndani ya CSS, tuna sheria mbili, kila moja ikilenga kipengele cha aya.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">

<p>example paragraph</p>
```

```css
p {
  color: blue;
}

p {
  color: green; 
}
```

:::

Prvi zakon postavlja boju teksta svih pasusa na plavu, dok drugi zakon postavlja boju teksta svih pasusa na zelenu.

Pa, koja boja će biti korišćena? Boja zelena će biti primenjena za elemente paragrafa.

Uzimajući u obzir odnos, poreklo i važnost, posebne sposobnosti i vizuelni raspored, Algoritam Cascade osigurava da CSS vaš radi prediktivno, omogućavajući vam da dizajnirate veb stranice sa kompleksnijom i detaljnijom strukturom.
