# --interactive--

Saznajte o `innerText`, `textContent`, i `innerHTML`.

Hizi ni sifa ambazo unaweza kupata katika JavaScript ili kupata au kubadilisha yaliyomo ya kipengee cha HTML. Hata kama zinaweza kuonekana kama sawa mwanzoni, zina tofauti muhimu. Kuchagua sifa sahihi hutegemea matumizi yako maalum, kwa hivyo tuanze.

Tuanze na `innerText`.

`innerText` inawakilisha maudhui ya maandishi yanayoonekana ya kipengee cha HTML na mzao wake. Sifa hii haijumuishi maandishi yaliyofichwa au lebo za HTML, bali maandishi tu yaliyoonyeshwa.

Kwa mfano, hapa unaweza kuona kipengee cha `div` chenye aya mbili:

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
```

Ako dobijemo referencu na ovaj HTML element u našem JavaScript kodu pomoću metode `getElementById()`, možemo pristupiti njegovom svojstvu `innerText`.

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.innerText);
```

:::

Ovo je unutrašnji sadržaj ovog elementa:

```md
Hello, World!
I'm learning JavaScript
```

Sifa hii inarudisha mfuatano wa herufi wenye maandishi yaliyomo ndani ya kipengee, ikiwa ni pamoja na maandishi kutoka kwa mzao wake.

Unapaswa kujua kwamba `innerText` inarudisha tu maandishi yanayoonekana wakati huo hasa ambapo mfuatano wa herufi unapoombwa. Ikiwa nodi ya mtoto imefichwa, maandishi yake hayatakuwa yanayoonekana.

Huu ni mfano ambapo aya ya pili imefichwa:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
```

:::

Ikiwa tutajaribu kuandika tena `innerText`, sasa matokeo hayatakuwa na maandishi ya aya ya pili:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.innerText);
```

:::

Možete umetnuti `innerText` elementa HTML ovako, ali ovo će modifikovati postojeći tekst i dodati funkciju prekoračivanja linije (`br`) za svaki prekid linije:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
container.innerText = "JavaScript is awesome!";
```

:::

Pošto ``innerText`` se bavi vizuelnim aspektima, dobijanje njegove vrednosti izaziva proces koji se naziva "reflow", koji ponovo računa pozicije određenih elemenata na veb stranici. Ovaj proces može biti težak za računar, stoga ga treba izbegavati ako je to moguće.

Dobro. Sada hajde da pričamo o `textContent`.

`textContent` Obnavlja standardni tekstualni sadržaj elementa, uključujući sav tekst unutar njegovih potomaka.

Ključna razlika između `innerText` i `textContent` je u tome što `textContent` uvek vraća sav tekstualni sadržaj elementa sa HTML i njegove potomke, bez obzira na to da li su vidljivi ili skriveni.

Ovde imamo isti primer u HTML:

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
```

Ako pokušate da dobijete ovaj atribut, videćete tekst elementa i njegovog potomka kao rezultate, čuvajući doslednost i poziciju:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.textContent);
```

:::

Ako element HTML nije vidljiv, kao što možete da vidite ovde gde smo sakrili drugi pasus, njegov tekst će i dalje biti uključen u ovaj atribut:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
console.log(container.textContent);
```

:::
  
`textContent` takođe uključuje sadržaj komponenti kao `script` i `style`.

Ako pokušate da promenite vrednost `textContent` na čvoru, on će pronaći sve svoje potomke čvorove i zameni ih jednim tekstualnim čvorom sa novom sekvencijom:

:::interactive_editor

```html
<div id="container">
  <p>Hello, World!</p>
  <p hidden>I'm learning JavaScript</p>
</div>
<script src="index.js"></script>
```

```js
const container = document.getElementById("container");
container.textContent = "New content";
```

:::

Na hatimaye, tuzungumzie jinsi `textContent` na `innerText` zinavyotofautiana na `innerHTML`.

Zapamtite da za `innerHTML` možete umetnuti sadržaj HTML unutar elementa. Ovo je pomoć pri unosu novog HTML u DOM putem promena.

Hata hivyo, kumbuka kwamba hii inaleta hatari ya usalama ikiwa huna udhibiti juu ya mfuatano, kama vile mfuatano unaojumuisha data iliyowekwa na mtumizi. Ikiwa data hiyo ni hatari, inaweza kusababisha matatizo makubwa ya usalama.

Ili kuepuka hili, inashauriwa kutumia sifa ya `textContent` kuingiza maandishi ya kawaida badala yake.

Sifa za `innerText`, `textContent`, na `innerHTML` katika JavaScript hutoa njia tofauti za kupata na kudhibiti yaliyomo ya vipengee vya HTML. Unapaswa kuelewa tofauti kati ya sifa hizi ikiwa lengo lako ni kufanya kazi na maudhui ya HTML kwa ufanisi katika JavaScript.
