# --interactive--

Katika mafundisho yaliyopita, tumekuwa tukifanya kazi na sifa ya `grid-template-columns` na kuweka thamani kwa sehemu chache za sehemu.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="grid-container">
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
</div>
```

```css
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr 1fr;
  column-gap: 10px;
}

.box {
  width: 100px;
  height: 100px;
  background-color: darkblue;
}
```

:::

Iako je sledeći kod potpuno validan, postoji jednostavan način da ponovite sve sekcije ili liste vaših ruta.

Kitendakazi cha `repeat()` kinatumika kurudia sehemu au orodha zote za njia kwa safu au nguzo. Kitendakazi hiki kinapokea idadi ya kurudia na njia unazotaka kurudia.

Ovde je revidirana verzija originalnog primera koristeći funkciju 'repeat':

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="grid-container">
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
</div>
```

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  column-gap: 10px;
}

.box {
  width: 100px;
  height: 100px;
  background-color: darkblue;
}
```

:::

Hakutakuwa na mabadiliko kwa mitindo katika kivinjari, lakini hii ni njia fupi zaidi ya kuandika thamani zinazorudiwa kwa nguzo.

Kitendakazi cha `repeat()` kitakubali muundo wowote halali unaoweza kutumia kwa safu au nguzo.

Ovde je primer korišćenjem funkcije `repeat()` za postavljanje prve i treće kolone na 20 piksela, a druge i četvrte kolone na jednu frakcionu jedinicu.

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="grid-container">
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
  <div class="box"></div>
</div>
```

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(2, 20px 1fr);
  column-gap: 10px;
}

.grid-container div {
  height: 100px;
  background-color: darkblue;
}
```

:::

Wakati mwingine, unaweza kuchagua kuandika kila thamani binafsi badala ya kutumia kitendakazi cha `repeat()`. Lakini kuna nyakati ambapo kitendakazi hiki kinakuwa cha msaada, hasa unapotaka kurudia muundo fulani kwa orodha ya njia.
