# --interactive--

CSS Grid je moćan sistem za organizaciju koji omogućava mrežnim programerima da lako kreiraju složene i prilagodljive postavke uređaju.

Zamislite kada raspoređujete nameštaj u sobi – CSS Mreža je kao da imate nevidljivu mrežu na podu koja vam pomaže da sve postavite tačno na svoje mesto.

Tunapojenga tovuti, mara nyingi tunahitaji kupanga vipengele tofauti kwenye ukurasa.

Pre CSS Grid-a, ovo je ponekad predstavljalo izazov, naročito za složene rasporede. CSS Grid pojednostavljuje ovaj proces tako što deli veb stranicu na redove i kolone, stvarajući mrežni raspored.

Fikiria unafanya kazi na kontena `div` yenye vipengele vingi vilivyopangwa ndani kama hivi:

:::interactive_editor

```html
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
  <div class="item">Item 4</div>
  <div class="item">Item 5</div>
  <div class="item">Item 6</div>
</div>
```

:::

Ikiwa ungependa kupamba vipengele hivyo kwa muundo wa gridi, unaweza kuweka `display` kuwa `grid` na kutumia nguzo kama hivi:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
  <div class="item">Item 4</div>
  <div class="item">Item 5</div>
  <div class="item">Item 6</div>
</div>
```

```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-gap: 20px;
}

.item {
  background-color: lightgray;
  padding: 20px;
  text-align: center;
  border: 1px solid #ccc;
}
```

:::

Katika msimbo huu, tunamwambia kivinjari kuunda gridi yenye nguzo tatu zenye upana sawa, hiyo ndiyo maana ya `1fr 1fr 1fr`, na tunaongeza pengo la pikseli 20 kati ya kila kipande cha gridi.

Sasa, unaweza kuwa unajiuliza: "Je, Flexbox je? Je, siyo pia hutumika kwa mipangilio?"

Uko sahihi! Flexbox ni mfano mwingine wa upangaji wa CSS, na pia ni mzuri sana. Lakini kuna tofauti muhimu.

Flexbox ni wa mwelekeo mmoja, wakati Grid ni wa mwelekeo miwili. Hii ina maana Flexbox inafaa kwa kupanga vitu katika safu moja au nguzo moja, wakati Grid ni bora kwa kuunda mipangilio yenye safu na nguzo zote mbili.

Flexbox huanza na maudhui, ikibadilisha muundo kulingana na maudhui. Grid, kwa upande mwingine, huanza na muundo, ikikuruhusu kuunda muundo kisha kuweka vitu ndani yake. Grid inakupa udhibiti sahihi zaidi wa mahali pa vitu. Unaweza kusema kipande hasa ni safu gani na nguzo gani kiwe.

Evo primera Flexbox-a za poređenje:

:::interactive_editor

```html
<link rel="stylesheet" href="styles.css">
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
  <div class="item">Item 4</div>
  <div class="item">Item 5</div>
  <div class="item">Item 6</div>
</div>
```

```css
.container {
  display: flex;
  justify-content: space-between;
}
```

:::

Ovo stvara prilagodljivi uređaj gde su komponente raspoređene ravnomerno duž glavne ose.

I Grid i Flexbox imaju svoje snage, a često najbolje konfiguracije koriste kombinaciju oba. Možete koristiti Grid za opšti raspored stranice, pa zatim Flexbox za aranžiranje elemenata unutar svake ćelije mreže.

Ukratko, CSS Grid je moćan alat koji omogućava precizno podešavanje u dva pravca. Iako može delovati teško na početku, uz vežbanje, postaje važan alat za kreiranje složenih i prilagodljivih podešavanja u zavisnosti od uređaja.
