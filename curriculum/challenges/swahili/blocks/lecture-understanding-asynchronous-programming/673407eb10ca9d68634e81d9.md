# --description--

API geolokacija pruža način da sajt zatraži pristup lokaciji korisnika. Važno je razumeti da, iz razloga privatnosti, korisnik mora dati dozvolu pre nego što se njegova lokacija može pristupiti putem sajta.

Glavna metoda na koju ćemo danas fokusirati se je `getCurrentPosition`. Ova metoda se koristi za prikupljanje geografske lokacije uređaja. Evo primera kako možete koristiti `getCurrentPosition`:

```js
navigator.geolocation.getCurrentPosition(
  (position) => {
    console.log("Latitude: " + position.coords.latitude);
    console.log("Longitude: " + position.coords.longitude);
  },
  (error) => {
    console.log("Error: " + error.message);
  }
);
```

Katika msimbo huu, tunaita `getCurrentPosition` na kumpa kitendakazi ambacho kitaitwa wakati nafasi itakapopatikana kwa mafanikio. Kielelezo cha nafasi kina vipengele mbalimbali vya taarifa, lakini tunazingatia `latitude` na `longitude` pekee.

Kama kuna tatizo katika kupata nafasi, basi kosa litaandikwa kwenye konsoli.

Metoda `getCurrentPosition` koristi GPS, Wi-Fi mreže ili pristup lokaciji putem IP adrese, zavisno od uređaja i njegovih podešavanja. Kada je lokacija dostupna, callback funkcija za uspeh poziva sa objektom lokacije.

Kielelezo cha nafasi kina vigezo mbalimbali, ambapo vinavyotumika zaidi ni `latitude` na `longitude`, lakini pia kinaweza kujumuisha `altitude`, `accuracy`, `speed`, `heading`, na kadhalika.

Jambo moja muhimu la kuzingatia unapotumia geolocation ni faragha ya mtumizi. Hakikisha unaeleza kwa watumizi wako kwa nini unahitaji data ya eneo lao na jinsi utakavyotumia data hiyo.
